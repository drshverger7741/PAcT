# Activity Monitor (PAcT)

Локальный сервис для мониторинга активности пользователя в Windows с веб-интерфейсом.

## Функционал
- Отслеживание состояний: Активен, Простой, Заблокирован, Сон.
- Веб-интерфейс на FastAPI + HTMX + PicoCSS (все зависимости локальные, работает без интернета).
- Настройка параметров через веб-интерфейс (порог бездействия, частота опроса, интервал сохранения).
- Хранение данных в локальной БД SQLite.
- Работает без внешних зависимостей (кроме Python библиотек) через WinAPI.

## Как запустить

### Из исходного кода
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервис:
   ```bash
   python main.py
   ```
3. Откройте в браузере: `http://localhost:8765`

### Как остановить
- **Веб-интерфейс:** Перейдите в "Настройки" и нажмите кнопку "Выключить сервис". Это самый надежный способ корректно сохранить данные и закрыть программу.
- **Консоль:** Нажмите `Ctrl+C`.
- **Диспетчер задач:** Завершите процесс `PAcT.exe` (или `python.exe` / `pythonw.exe`). **Важно:** Перед повторной сборкой через PyInstaller обязательно убедитесь, что старая версия `PAcT.exe` закрыта.

## Как это работает (Частота проверок)
1. **Активность (мышь/клавиатура):** Проверяется с заданным интервалом (настраивается, по умолчанию **5 секунд**). Если за это время не было ввода, и общее время бездействия превысило порог, статус меняется на "Простой".
2. **Блокировка экрана и Сон:** Отслеживаются **мгновенно** через системные события Windows (Event-driven).
3. **Сохранение в БД:** Данные сбрасываются из памяти в файл `activity_monitor.db` с заданным интервалом (настраивается, по умолчанию **30 секунд**) или при смене состояния.

## Автозагрузка (Windows)
Чтобы сервис запускался при старте системы:
1. Нажмите `Win + R`, введите `shell:startup` и нажмите Enter.
2. Создайте ярлык для `PAcT.exe` (из папки `dist`) в открывшейся папке.
3. **Окно консоли:** При запуске `exe` окна консоли не будет (настроен режим `noconsole`).
4. *Для запуска из исходников без консоли:* используйте `pythonw.exe main.py`.

## Сборка в автономный файл (.exe)
Для сборки используется PyInstaller. Полученный файл будет **полностью автономным**: для его запуска на других компьютерах с Windows **не требуется установка Python**. При этом приложение будет работать в фоновом режиме **без окна консоли**.

1. Установите PyInstaller и зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сборку:
   ```bash
   pyinstaller build.spec
   ```
3. Результат будет в папке `dist/PAcT.exe`. Этот файл можно переносить и запускать на любом компьютере с Windows (10/11).

## Разработка
- `tracker.py` — логика отслеживания (WinAPI).
- `db.py` — работа с SQLite (aiosqlite).
- `web.py` — API и веб-сервер (FastAPI).
- `templates/` — HTML шаблоны (Jinja2).
